# Weekly review
1. Read the last 7 days of journal.md and progress.md.
2. Report: units mastered this week, planned vs actual day, recurring mistakes, confidence-vs-correctness pattern, hours actually spent.
3. Run a 10-minute mixed retrieval quiz from the review queue.
4. Re-plan: if behind, propose a concrete catch-up (which units compress, which defer) or an honest timeline change. Ask me to confirm.
5. Write the result to progress.md and journal.md.
