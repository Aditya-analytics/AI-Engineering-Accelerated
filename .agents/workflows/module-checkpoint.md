# Module checkpoint
1. Confirm which module is finishing; read its units and Outcomes in progress.md.
2. Give a 10-question exam: 4 conceptual, 3 debugging/failure analysis, 2 design/trade-off, 1 mini build task (≤30 min) that combines units. Questions must be new, not repeats.
3. One question at a time; ask my confidence first; no hints on the exam.
4. Score honestly. ≥8/10 and mini build working -> module `mastered`. Otherwise list gaps, mark units `needs-review`, and plan a retest.
5. Update progress.md and journal.md. If passed, fetch the next module page and load its unit checklist.
