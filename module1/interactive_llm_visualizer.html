Here are the exact weights used for this Micro-LLM ($D_{model}=4, V=12$). The LM Head transforms the 4 hidden values of the last token into 12 logits. 

# The exact core math powering every LLM:

def matmul(vec, matrix):
    """
    1D Hidden State (D=4) @ 2D LM_Head (4 x V=12)
    Returns: 12 unnormalized Logits
    """
    D = len(vec)
    V = len(matrix[0])
    logits = [0.0] * V
    for v in range(V):
        logits[v] = sum(vec[d] * matrix[d][v] for d in range(D))
    return logits


def softmax(logits, temperature=1.0):
    """
    Turns logits into probabilities that sum to 100%
    """
    if temperature <= 0.0001:
        # Greedy decoding (Argmax)
        max_idx = logits.index(max(logits))
        return [1.0 if i == max_idx else 0.0 for i in range(len(logits))]

    # Exponentiate with temperature scaling
    exp_scores = [math.exp(x / temperature) for x in logits]
    total = sum(exp_scores)
    return [score / total for score in exp_scores]

1. The Linear Projection

The Language Model Head is a single matrix multiplication without activation:

Logits = h × W_vocab

Dimension: [1 × 4] × [4 × 12] = [1 × 12].

2. Softmax Normalization

Converts the real numbers $(-\infty, +\infty)$ into a valid probability simplex:

P(token_i) = exp(logit_i / T) / Σ exp(logit_j / T)

3. Sampling with Temperature

  • T → 0 (Greedy): Exponent goes to infinity; top logit gets 1.0 (100%).
  • T = 1.0: True distribution learned from training corpus.
  • T > 1.0: Exponents are compressed closer together, increasing entropy (randomness).
